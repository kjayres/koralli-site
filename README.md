# Koralli old site

Public Squarespace website saved on 13 November 2026 before moving koralli.io to the new site. This branch is an archive; the live site remains on `main`.

## Open the archive

Download or clone this branch, then run `python3 -m http.server 8767` in this folder. Open http://localhost:8767/site/_index.html to browse all 53 saved pages.

- `site/`: independent static pages with local images, styles and fonts.
- `original/pages/`: captured HTML before the offline adaptations.
- `original/manifest.json`: source URLs and saved-file mappings.
- `files/`: deduplicated copies of downloaded assets and source files.
- `verification.json`: verification results.

All 4,194 local references resolve, and the visible text from all 53 original pages is retained. External article links remain external. Squarespace scripts, tracking and server features are disabled in the static copy; visual effects are simplified and the mobile menu uses a small local script. Browser visual review remains outstanding because the connected browser could not be controlled.

This is a public-site archive, not an editable Squarespace export. It does not contain unpublished drafts, private form submissions, account settings, analytics or other private account data. If those are needed, the account owner must export them separately before cancellation.

Keep the koralli.io domain registration and EDIS DNS/email services active. Cancel only the Squarespace website subscription after confirming the new site works over HTTPS and checking this archive.
